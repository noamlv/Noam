# Investigacion fuente

Esta carpeta recibe documentos de investigacion antes de convertirlos en contenido publico de NOAM.

## Carpetas de entrada

- `inbox/electoral/`: estudios, tendencias, actores, calendario, metodologia y oportunidades electorales.
- `inbox/dataperu/`: fuentes, indicadores, necesidades territoriales, sectores y oportunidades de producto.

## Flujo editorial

1. Depositar el archivo Markdown original en la carpeta correspondiente.
2. Revisar afirmaciones, fechas, cifras, enlaces y derechos de publicacion.
3. Separar evidencia verificable, interpretacion y recomendaciones.
4. Definir el destino publico: insight, indicador, toolkit, producto, servicio o landing.
5. Adaptar el contenido aprobado a MDX dentro de `content/` o a una ruta de la aplicacion.

Los archivos de `docs/research/` son insumos internos. No se publican automaticamente en el sitio.

## Nombres recomendados

Usar minusculas, fecha y tema, sin espacios:

- `2026-07-panorama-electoral-regional.md`
- `2026-07-demanda-datos-municipales.md`
